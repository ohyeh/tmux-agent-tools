# v0.5.0 Release Readiness

This file records the release-prep evidence for `v0.5.0`. It is intentionally limited to local validation, release-note readiness, and the planned dry-run workflow path. It does not create a tag, GitHub Release, or Homebrew Formula bump.

## Scope

- Target version: `v0.5.0`
- Release notes source: `CHANGELOG.md`
- Release workflow: `.github/workflows/release.yml`
- Release-prep branch: `feature/v0.5-release-prep`
- Release date in changelog: `2026-05-17`

## Release Candidate Surface

`v0.5.0` is the observability and multi-session composability release. The implemented surface on `main` includes:

- bounded session inventory polling with `tmux-agent-sessions list --watch --json --count N --interval S`;
- nullable wrapper `status --json` `exit_code` detail;
- explicit transcript validation with `tmux-agent-dialogue validate-transcript --schema-version 1`;
- local blocked-session trigger artifacts with `--on-blocked-trigger`;
- structured `tmux-agent-dialogue summarize --output-format json`;
- scriptable cleanup preview coverage;
- participant profile timeout overrides;
- explicit GitHub comment edit mode with `github-comment --edit-existing <comment-id>`;
- empty summary-file and `--max-bytes` truncation coverage.
