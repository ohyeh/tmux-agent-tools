## Important Context

### NEVER do this (footguns documented in memory)

- `local path=` / `local cdpath=` / etc — zsh ties these to PATH/CDPATH and clobbers them silently
- `local status=` — zsh's `status` is read-only, crashes the script
- `local foo` (no =val) in a re-entered scope — zsh PRINTS the existing value to stdout
- `jq -c ...` without `-n` when not piping — jq reads parent's stdin → hangs
- `( eval ... ); var=$?` under `set -e` — fires set -e between commands, use `|| var=$?`
- Bare `> file 2>/dev/null` in zsh — shell's redirect-open error escapes; wrap in subshell
- `local violations=0` at script top-level (outside function) — zsh forbids; use `typeset`
