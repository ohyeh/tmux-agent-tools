## Codebase Understanding

### Architecture Overview

- `agent-tmux <cli>` is the single ~6.8k-line zsh engine; `claude-tmux`/`codex-tmux`/`agy-tmux` are 3-line `exec agent-tmux <cli>` shims. New CLIs are declarative profiles (`scripts/profiles/<cli>.conf`), not code.
- Script runs under `set -euo pipefail` — this matters (see Gotchas).
- Release is **GitHub Actions only** (`.github/workflows/release.yml`, workflow_dispatch): inputs `version` (vX.Y.Z), `prerelease`, `dry_run` (default true). Must run from `main`, requires a matching `## vX.Y.Z` CHANGELOG section, runs validation (zsh -n, ruby -c + brew style, self-tests, a curated test list, fake/fake dialogue smoke), then on `dry_run=false` tags + creates the release. Formula `url+sha256` is bumped in a SEPARATE post-release PR (the `release(formula): vX.Y.Z` pattern).
- Version carriers: `CHANGELOG.md` (`## vX.Y.Z`, grepped by release.yml) + 3× `plugin.json` + `Formula/*.rb`. As of this session they are unified at 0.26.1 (formula lags by design between release and its bump PR).
